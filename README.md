FpsPingDisplay
Displays FPS and Ping at the top left of the screen.

Requirements
Minecraft 1.21.11
Fabric Loader 0.16+
Fabric API
Java 21+
Installation
Install Fabric Loader for Minecraft 1.21.11
Download Fabric API and put it in .minecraft/mods/
Put FpsPingDisplay.jar in .minecraft/mods/
Launch Minecraft with the Fabric 1.21.11 profile
Features
FPS counter at the top left of the screen
Real ping measurement (RTT) using Minecraft's native QueryPingC2SPacket protocol
Updates every 2 seconds with median smoothing
White text with shadow for readability on any background
